# מערכת ניהול קליניקה - Clinic Management System

מערכת ניהולית מלאה (CRM + EMR) שתתווסף לאתר הקיים, בעברית RTL, מאובטחת, מבוססת Supabase. **מערכת הזמנת התורים הקיימת לא תשתנה** - היא תמשיך לעבוד כרגיל, והמערכת החדשה תקרא ותנהל את הנתונים שנוצרים ממנה.

## היקף העבודה

זהו פרויקט גדול מאוד (מוערך ב-40-60 קבצים חדשים, 8-12 טבלאות DB, ~15 מסכים). אני ממליץ לבנות בשלבים כדי לוודא איכות בכל חלק. להלן החלוקה המוצעת:

---

## שלב 1 - תשתית DB + Auth + Layout (הבסיס)
- הרחבת סכמת מסד הנתונים:
  - `patients` (פרופיל קבוע לכל ילד - שם, ת.ז, תאריך לידה, מין, הורה, טלפון, אימייל, כתובת, איש קשר חירום, הערות)
  - קישור `appointments` הקיימת ל-`patients` (עמודה `patient_id` + מיגרציה חכמה לפי ת.ז)
  - הוספת סטטוסים מורחבים ל-appointments (arrived, completed, no_show)
  - `treatments` (תיעוד טיפול מלא)
  - `payments` (תשלומים + ביטוח)
  - `insurance_claims` (הגשות לקופה)
  - `follow_up_reminders` (תזכורות מעקב)
  - `patient_files` (מסמכים ב-Storage)
  - `internal_notes` (הערות פנימיות)
  - `audit_log` (מעקב שינויים)
  - `therapists` (מטפלים - הכנה לעתיד)
  - Soft delete: עמודת `deleted_at` בכל הטבלאות הרלוונטיות
- הרחבת מערכת ההרשאות: `app_role` כבר קיים (admin) - נוסיף `therapist`, `secretary`
- RLS מלא + GRANTs לכל הטבלאות
- Trigger לרישום audit_log אוטומטי
- Storage bucket `patient-files` פרטי עם RLS
- Layout חדש למערכת הניהול עם sidebar בעברית RTL

## שלב 2 - ניהול מטופלים + Timeline
- דף רשימת מטופלים עם חיפוש מהיר (שם/טלפון/ת.ז)
- דף פרופיל מטופל עם טאבים:
  - פרטים אישיים
  - Timeline כרונולוגי (תורים, טיפולים, תשלומים, מסמכים, הערות)
  - מסמכים (העלאה/צפייה/הורדה)
  - הערות פנימיות
  - כספים
- כפתור "מטופל חדש" + טופס
- קישור אוטומטי בין תורים מהאתר למטופלים לפי ת.ז

## שלב 3 - תורים + לוח שנה
- לוח שנה יומי/שבועי/חודשי עם צבעי סטטוס
- Drag & Drop לתורים
- שינוי סטטוס מהיר (הגיע/בוצע/לא הגיע)
- מעבר מהיר לפרופיל המטופל בקליק
- כפתור "תיעוד טיפול" על כל תור שהושלם

## שלב 4 - תיעוד טיפולים
- טופס תיעוד טיפול מלא (סיכום, הערכה, מטרות, פעילויות, תגובה, התקדמות, המלצות, תרגילי בית, תוכנית הבאה)
- שאלת "האם נדרש תור נוסף?" - אם כן: תאריך + עדיפות → יוצר reminder אוטומטית
- היסטוריית טיפולים בפרופיל (immutable - never overwritten)

## שלב 5 - תשלומים + ביטוח
- טופס תשלום לכל טיפול (פרטי/ביטוח, ספק ביטוח, מחיר, ששולם, יתרה)
- דשבורד ביטוח: מטופלים ממתינים להגשה, סטטוסים, סכומים
- ייצוא Excel
- דשבורד פיננסי למטופל

## שלב 6 - Dashboard ראשי
- כרטיסי מדדים: תורים היום, הכנסות היום/חודש, מטופלים פעילים, תשלומים ממתינים
- גרפים (recharts) - הכנסות חודשיות, תורים לפי סטטוס
- רשימת תזכורות מעקב
- פעילות אחרונה מה-audit_log

## שלב 7 - דוחות + PDF + חיפוש גלובלי
- מחולל דוחות עם פילטרים (טווח תאריכים, מטפל, ביטוח, סטטוס וכו')
- ייצוא Excel לכל טבלה (`xlsx` library)
- הפקת PDF (`jspdf` + `jspdf-autotable`): סיכום טיפול, היסטוריית מטופל, דוח ביטוח, דוח התקדמות - עם לוגו וכותרת הקליניקה
- חיפוש גלובלי מה-header (מטופל/טלפון/ת.ז/הורה)
- מרכז התראות

## פרטים טכניים

**Stack:** נשארים על React + Vite + Tailwind + shadcn + Supabase (Lovable Cloud) הקיימים.

**Libraries חדשים שנתקין:**
- `xlsx` - ייצוא Excel
- `jspdf` + `jspdf-autotable` - הפקת PDF
- `recharts` - כבר כנראה קיים ב-shadcn
- `date-fns` - כבר קיים
- `@dnd-kit/core` - Drag & Drop ליומן

**ארכיטקטורה:**
- `src/pages/admin/*` - כל דפי הניהול
- `src/components/admin/patients/*`, `treatments/*`, `payments/*`, `dashboard/*`, `reports/*`
- `src/hooks/` - hooks לשליפת נתונים (react-query)
- `src/lib/pdf/` - יצרני PDF
- `src/lib/excel/` - יצואני Excel
- שימוש מלא ב-design tokens הקיימים (טורקיז/אלמוגי)

**אבטחה:**
- RLS על כל טבלה, כל הפעולות דרך `has_role(auth.uid(), 'admin')`
- Soft delete בלבד - `deleted_at IS NULL` בכל שאילתה
- Storage bucket פרטי - גישה רק ל-admin
- Audit log דרך triggers ב-DB (לא ניתן לזיוף מהקליינט)

**RLS לתפקידים עתידיים:** ה-policies יבנו כבר עכשיו לתמוך ב-admin/therapist/secretary דרך `has_role`, כך שהוספת תפקיד בעתיד = רק INSERT ל-user_roles.

## שאלות לפני התחלה

1. **האם להתחיל מעכשיו בשלב 1 (DB + Auth + Layout) ולהמשיך שלב-שלב באישור שלך?** או שאתה מעדיף שאבנה הכל ברצף גם אם ייקח מספר סבבים ארוכים?

2. **מחירי טיפולים:** האם יש מחיר קבוע לטיפול או שהמזכירה מקלידה בכל פעם? אם יש מחירון - כמה מחירים שונים?

3. **מטפלים:** כרגע יש מטפל אחד או כמה? (אם אחד - נכין את התשתית אבל לא נציג בחירה במסכים)

4. **לוגו הקליניקה ל-PDF:** יש לך קובץ לוגו? (אם לא - אשתמש בטקסט זמני "אוצר פעיל")

אחרי שתאשר את התוכנית ותענה על השאלות, אתחיל מיד בשלב 1.
